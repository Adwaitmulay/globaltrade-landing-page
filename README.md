# GlobalTrade — Responsive Landing Page

A modern, responsive landing page for a startup built using HTML, CSS, and JavaScript.

## Sections
- Navbar with hamburger menu for mobile
- Hero section with call to action
- Services section with 3 feature cards
- About section with company stats
- Testimonials from clients
- Contact form with validation
- Footer

## Features
- Fully mobile responsive using media queries
- Smooth scroll navigation
- Navbar hamburger toggle for mobile
- Scroll animations using Intersection Observer
- Contact form with JS validation
